CLI Options Reference

This document details the command line interface options available when running officeparser via npx or globally installed scripts.

Basic Usage

npx officeparser <file> [options]

Options can be passed in multiple formats: --key=value, --key value, as bare flags (e.g. --ocr which defaults to true), or negation flags (e.g. --no-ocr). Most options map directly to the OfficeParserConfig and GeneratorConfig properties, and you can access nested properties using JSON dot-notation (e.g. --htmlConfig.containerWidth=900px).

Available Flags

Flag Values Default Description
--to json | text | md | html | csv | rtf | pdf | docx | odt | tex | epub | chunks json The desired output format for the parsed document (latex is an alias of tex).
--output path (none) Write the generated output to a specified file instead of stdout.
--fileType docx | xlsx | pptx | odt | odp | ods | odg | pdf | rtf | csv | md | html | epub | tex (none) Explicitly override input file type detection (useful when input file lacks extension). .latex/.ltx files route to tex, and a .zip is routed by what it holds (an Overleaf project parses as tex).
--password string (none) Password for an encrypted document (PDF, OOXML, or ODF).
--ocr boolean false Enable Optical Character Recognition (OCR) for embedded images.
--ocrConfig.language string eng Tesseract OCR language(s) (e.g. eng, eng+fra).
--extractAttachments boolean false Extract embedded images and charts as Base64 data URIs.
--ignoreNotes boolean false Ignore footnotes, endnotes, and speaker notes.
--ignoreComments boolean false Ignore inline comments and threaded replies.
--ignoreHeadersAndFooters boolean false Ignore page headers and footers.
--ignoreSlideMasters boolean false Ignore slide master layouts and static template elements (PPTX/ODP).
--ignoreInternalLinks boolean false Skip internal anchors and bookmark links.
--ignorePageGeometry boolean false Omit per-node geometry (bounds) and page dimensions.
--pdfParserConfig.useTags boolean true Use the PDF's tagged-structure tree when present; set false to force geometry-only extraction.
--pdfParserConfig.detectColumns boolean true Recover reading order for multi-column and float-beside-text pages.
--pdfParserConfig.pageRange string '' (all) Restrict parsing to given pages, e.g. 1-3,7.
--htmlParserConfig.preserveComments boolean false Keep HTML and EPUB <!-- --> comments as comment nodes.
--texParserConfig.today string the date of the parse What \today prints in LaTeX input, e.g. --texParserConfig.today="May 1, 2024".
--pdfParserConfig.headingDetection auto | font-size | off auto How heading levels are decided for PDF content.
--newlineDelimiter string \n Delimiter string to use between lines/blocks in plaintext outputs.
--csvDelimiter string , Custom delimiter character for CSV files.
--includeRawContent boolean false Include the raw XML/RTF format strings within parsed nodes.
--serializeRawContent boolean true Include raw XML metadata directly in the AST properties.
--preserveXmlWhitespace boolean false Keep raw formatting spaces in XML parsing.
--includeBreakNodes boolean false Include explicit page/column break nodes (DOCX, ODF and LaTeX).
--verbose boolean false Show full error stack traces and warning logs on failures.
--includeFormatting boolean true Include formatting style map matching for generators.
--renderMetadata boolean false Render metadata block as visible content in the generated output.
--includeImages image-only | image+ocr-text | ocr-text-only | none image-only How an image node renders. Accepts both --includeImages=image+ocr-text and the space form --includeImages image+ocr-text; a bare --includeImages still means image-only, and --no-includeImages means none.
--maxInlineImageBytes number 1500000 Largest decoded image HTML/Markdown inlines as a data: URI. Over the cap, the image renders its recognized/OCR text when it has any, otherwise a name reference. 0 never inlines; standalone HTML always does.
--pdfParserConfig.mergeHyphenatedWords boolean true Rejoin words hyphenated across a line break.
--pdfParserConfig.normalizeText boolean true Unicode and ligature normalization of extracted PDF text.
--pdfParserConfig.extractTextColor boolean true Record each PDF run's fill colour in formatting.color. On by default; set false to skip the per-page operator-list fetch on a throughput-focused text path.
--ocrConfig.preserveLayout boolean true Keep the 2-D line layout of recognized text; false gives flat reading-order text.
--htmlConfig.containerWidth string | number auto HTML output container width (e.g. 900px, 100%, auto).
--textConfig.pageSeparator string \n Separator written between rendered pages in text output (\f for pdftotext-style form feeds).
--pdfConfig.engine html | native html PDF engine: Puppeteer through generated HTML, or native (pdf-lib, no browser).
--texConfig.bundle boolean false LaTeX: write a zip of main.tex plus its images/ instead of the .tex alone.
--texConfig.embedImages boolean true LaTeX: false refers to images/ files instead of carrying PNG and JPEG images inside the .tex.
--texConfig.documentClass auto | article | report | book | beamer auto LaTeX document class (auto = beamer for presentations, article otherwise).
--texConfig.standalone boolean true LaTeX: false writes the body only, for pasting into an existing document.
--format json | text | md | html | csv | rtf | pdf | docx | odt | tex | epub | chunks json Deprecated. Use --to instead.
--toText Removed in v8. Use --to=text instead.
--ocrLanguage Removed in v8. Use --ocrConfig.language instead.
--putNotesAtLast Removed in v8. Notes are attached structurally via node.notes.
--outputErrorToConsole Removed in v8. Use --verbose instead.

Each removed flag above exits with status 1 and prints its replacement, rather than being accepted and ignored. An unrecognized or renamed config key (say --ocrConfig.autoTerminateTimeout) is not fatal, but the CLI always prints the UNRECOGNIZED_CONFIG_OPTION warning naming its replacement, with or without --verbose, and likewise INVALID_CONFIG_VALUE for a value an option does not accept (--texConfig.documentClass=reprot) and INVALID_CONTAINER_WIDTH.


Examples

Generate HTML Preview

npx officeparser report.docx --to html --output preview.html --htmlConfig.containerWidth=800px

Extract RAG Chunks with OCR

npx officeparser presentation.pptx --to chunks --ocr --ocrConfig.language=eng --output chunks.json

Plain Text Extraction

npx officeparser data.pdf --to text --ignoreNotes

Convert LaTeX to DOCX

npx officeparser paper.tex --to docx --output paper.docx

# An Overleaf "Download source" zip also brings its \input files and images
npx officeparser overleaf-project.zip --extractAttachments --to docx --output paper.docx

A .tex holds only the files it carries in filecontents blocks (as officeParser's LaTeX output carries its images). Other files it includes or images it shows are reported with the LATEX_FILE_NOT_FOUND warning, and images are kept as references to their path. Parse the project .zip to include them.

Convert DOCX to EPUB

npx officeparser book.docx --extractAttachments --to epub --output book.epub
[!IMPORTANT] --extractAttachments is required when converting to EPUB if the document has images; without it, no image bytes are available for the EPUB generator to package.
