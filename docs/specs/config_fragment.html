officeParser Configuration Specification

This document details the configuration options available for the officeParser library. These options directly influence how the document structure is interpreted and what data is extracted into the Final AST.

Related: GeneratorConfig (the generate side) · AST structure · OfficeConverter · CLI flags · Debugging

OfficeParserConfig

The OfficeParserConfig object is used as the second argument to parseOffice. All properties are optional.

Property Type Default Description (In Action)
onWarning function undefined Error Handling: Callback for non-fatal issues (OCR failures, malformed nodes). Allows the parser to continue while you capture diagnostic info.
abortSignal AbortSignal | null null Cancellation: An optional signal to abort the parsing operation. Interrupts heavy loops, PDF page parsing, zip decompression, and active OCR processes cleanly. Rejects with an AbortError.
newlineDelimiter string \n Text Flattening: Determines the string inserted between structural blocks (paragraphs, cells, slides) when calculating the pre-flattened .text property. Change to <br> for HTML-ready output.
ignoreNotes boolean false Note Filtering: Specifically targets PowerPoint (PPTX/ODP) and LaTeX beamer (\note) speaker notes and document footnotes/endnotes (DOCX, ODT, RTF, PDF, HTML, Markdown, EPUB, and LaTeX \footnote/\endnote). If true, notes are entirely omitted from the AST output.
ignoreComments boolean false Comment Filtering: When true, inline comments and annotations are excluded from parsing. Affects DOCX, XLSX, PPTX, ODF (ODT/ODS/ODP) and LaTeX (a % Comment (Author, date): text line, the shape the LaTeX generator writes; other % comments are always discarded). By default comments are attached to their target node via node.comments[]. Source-level comments (CSV # rows, Markdown/HTML <!-- -->, LaTeX % <!-- --> lines) are not governed by this flag.
ignoreHeadersAndFooters boolean false Layout Element Filtering: When true, headers and footers are not parsed. Applies to DOCX, PDF, ODF (ODT master pages only) and LaTeX (fancyhdr). When false (default), they are extracted into ast.auxiliary.headers and ast.auxiliary.footers.
ignoreSlideMasters boolean false Template Filtering: When true, PPTX slide masters are not parsed. When false (default), they are extracted into ast.auxiliary.slideMasters.
extractAttachments boolean false Resource Extraction: Enables the collection of images, charts, and embedded objects. Populates the root attachments array and ensures image nodes have attachmentName metadata. For LaTeX, image bytes exist only when parsing a project .zip; images in a bare .tex stay references to their path (metadata.url).
includeRawContent boolean false Source Inspection: Adds a rawContent property to every node containing its original XML or RTF source. Warning: Significantly increases AST memory footprint.
serializeRawContent boolean true XML Cleanliness: When includeRawContent is true, re-serializes raw XML to clean strings. If false, extracts original raw substring.
preserveXmlWhitespace boolean false Formatting Fidelity: When serializeRawContent is true, preserves original XML whitespace and line endings during serialization.
ocr boolean false Vision Synthesis: Enables optical character recognition for images and non-selectable PDF layers. OCR runs over extracted images, so it also requires extractAttachments: true in every format; ocr: true alone performs no OCR and warns OCR_REQUIRES_ATTACHMENTS. Requires Tesseract.js.
pdfWorkerSrc string (CDN) PDF Engine: Path to the pdf.worker.js. Must be accessible by the browser.
ocrConfig object language: 'eng', preserveLayout: true OCR Scheduler: Fine-grained settings for the intelligent worker pool. Populated defaults (language 'eng', layout preserved, worker/timeout defaults), not an empty object.
ocrConfig.language string eng Language Training: Specifies Tesseract languages (e.g., 'eng+fra').
ocrConfig.preserveLayout boolean true 2-D OCR Layout: Rebuild the recognized text's spatial page layout from per-word bounding boxes (columns line up, right-hand text stays on the right) instead of a flat reading-order string. Set false for the plain linearized text.
ocrConfig.timeout object {} OCR Timeouts: Consolidated timeout configurations. The consolidated timeout object is the only form.
ocrConfig.timeout.autoTerminate number 10000 Lifecycle Safety: Inactivity timeout in ms of inactivity before the OCR worker pool is terminated and freed. Set to 0 to disable.
ocrConfig.timeout.workerLoad number 60000 Load Protection: Timeout in ms for initializing/loading a Tesseract worker or downloading .traineddata files. Exceeding this evicts/terminates the worker process and logs a warning. Set to 0 to wait indefinitely.
ocrConfig.timeout.recognition number 30000 Recognition Guard: Timeout in ms for the actual text-recognition call. Exceeding this evicts/terminates the worker process and logs a warning. Set to 0 to wait indefinitely.
ocrConfig.abortSignal AbortSignal | null null OCR Cancellation: Automatically propagated from the top-level abortSignal. Used to interrupt queued or executing OCR tasks.
ocrConfig.workerPath / corePath / langPath string '' Offline Environments: Paths to Tesseract scripts and data files for air-gapped or customized installations.
includeBreakNodes boolean false Line/Page Break Parsing: Supported for Word (DOCX), OpenDocument (ODT/ODP/ODS) and LaTeX (\newpage/\clearpage as page breaks) files. ODF carries page and column breaks on the paragraph style (fo:break-before/fo:break-after) rather than as an inline element, so those surface as breaks emitted around the paragraph. When set to true, officeParser will extract physical breaks into the AST as break nodes. This includes standard line breaks (textWrapping), hard carriage returns (carriageReturn), page breaks (page), column breaks (column), and soft layout markers (lastRenderedPage).
ignoreInternalLinks boolean false Link Filtering: When true, all bookmarks, cross-references, and internal document jumps are stripped from the AST. Only external URLs will be preserved. Honored for PDF as of v8, and for LaTeX \label, \ref/\eqref/\autoref and \hyperref (a reference still reads as the number it refers to, without the link).
ignorePageGeometry boolean false Page Geometry: When true, the geometric layout data (each node's bounds box, its { x, y, width, height } on the page, plus page dimensions) is omitted. Currently produced by the PDF parser; page geometry is emitted by default (ignorePageGeometry defaults to false).
password string '' Encryption: Password for a password-protected document. Applies to every encryptable format: PDF, encrypted OOXML (.docx/.xlsx/.pptx, ECMA-376 agile or standard AES) and encrypted ODF (.odt/.ods/.odp/.odg, AES-CBC with PBKDF2). A missing password rejects with PASSWORD_REQUIRED, a wrong one with PASSWORD_INCORRECT. Ignored for unencrypted files. ODF note: LibreOffice 24.8+ defaults to AES-256-GCM with Argon2id ("wholesome encryption"), which is not supported and rejects with DOCUMENT_DECRYPTION_FAILED; re-save with the classic AES-CBC/PBKDF2 scheme (or an earlier LibreOffice) to parse it.
onPassword (reason) => string | undefined | Promise (none) Lazy password: Called ('required'/'incorrect') when an encrypted document needs a password password did not satisfy, so it can be supplied interactively (prompt/vault). Return one to retry (capped), or undefined to reject.
pdfParserConfig PdfParserConfig {} PDF Options: useTags, detectColumns, mergeHyphenatedWords, lineToleranceFactor, spaceToleranceFactor, headingDetection (auto/font-size/off), pageRange (e.g. 1-3,7), normalizeText, and extractTextColor (per-run fill color into formatting.color; on by default, set false to skip the per-page operator-list fetch on a throughput-focused text path).
fileType SupportedFileType | null null Authoritative Hint: Manually specify the source format. Essential when parsing md, html, csv, or tex from a Buffer / ArrayBuffer / Uint8Array, as these lack magic byte markers. .latex/.ltx files route to tex, and a file named .zip is routed by what the archive holds (an Overleaf project or texConfig.bundle zip parses as tex).
csvDelimiter string , Data Parsing: Custom delimiter for CSV files (e.g., ; or \t).
decompressionLimits object {} Archive Limits: Settings to limit resources used during ZIP extraction to protect against excessive memory and resource usage. Apply to every ZIP-backed input, LaTeX project zips included.
decompressionLimits.maxUncompressedBytes number 536870912 (512MB) Decompression Limit: Maximum allowable uncompressed size in bytes for the ZIP archive contents. Any value >= 0 is taken literally, so 0 rejects all content; there is no unlimited/disable sentinel. Only a negative or non-finite value falls back to the 512MB default.
decompressionLimits.maxZipEntries number 10000 ZIP Entry Limit: Maximum number of files (entries) allowed inside the ZIP archive.
decompressionLimits.maxTableCells number 1000000 Cell Expansion Limit: Maximum number of table cells materialized from table:number-columns-repeated/table:number-rows-repeated in any ODF table (spreadsheet grids and embedded tables in ODT/ODP/ODG alike). Beyond it, expansion clamps and warns instead of allocating without bound.
htmlParserConfig object {} HTML/XHTML/EPUB parsing options.
htmlParserConfig.preserveAttributes boolean false Keep generic source attributes no typed field consumed on node.htmlAttributes (sanitized in and out).
htmlParserConfig.preserveIframes boolean | string[] false Preserve non-YouTube <iframe> embeds (otherwise dropped) as embed nodes. true preserves any; an array is a hostname allowlist (exact host or a .-suffix). The src is scheme-checked on generation, so a javascript:/data: src never survives. Also governs a raw <iframe> block in Markdown input.
htmlParserConfig.preserveComments boolean false Keep <!-- ... --> comments in HTML and EPUB input as comment nodes (metadata.sourceSyntax: 'html', raw body in text) instead of dropping them. Conditional comments (<!--[if …]>) are always dropped. HTML and EPUB only: comments in Markdown are always kept. The data-html-comment shape sourceAttributes emits is always read.
htmlParserConfig.embedFolkForms boolean false Import ambiguous "folk" embed forms in Markdown as (safe, id-rendered) YouTube embeds: a standalone Obsidian image whose URL is a YouTube link (![](…watch?v=ID)), and the clickable thumbnail-link ([![](…/vi/ID/…)](watch)). Off by default because auto-upgrading an image/link is a heuristic that could mangle a genuine image link; the unambiguous forms (data-youtube-video, a YouTube <iframe>, the ::youtube directive) are always recognized regardless.
texParserConfig.today string '' What \today prints in LaTeX input. '' prints the date of the parse, as LaTeX prints the date of the compile, written the way the document's language writes a date ("September 25, 2026" in English). Set a fixed date, so that the same file parses the same way every day, or a placeholder of your own to find and replace later. A value that is not a string raises INVALID_CONFIG_VALUE and is ignored.

OCR Scheduler & Resource Management (Smart Pool)

Using OCR initializes a persistent **Smart Worker Pool** to improve performance for subsequent requests.

  • Dynamic Affinity: Workers persist with their language affinity.
  • Smart Re-initialization: If a new language is requested at capacity, the Least Recently Used (LRU) idle worker is re-initialized instead of a full pool reset.
  • Automatic Cleanup: Workers are killed after the configured timeout of inactivity.

OfficeParser.terminateOcr()

A static method that immediately kills all active OCR workers. Call this in short-lived scripts (CLI) to bypass the inactivity timer and exit the terminal immediately.

await OfficeParser.terminateOcr();

Common Scenarios

1. Search Engine Indexing (High Speed)

const config = {
    ignoreNotes: true,
    extractAttachments: false, // Don't need images for indexing
    newlineDelimiter: ' '      // Simple space for search ranking
};

2. Document Reconstruction (Rich Data)

const config = {
    extractAttachments: true,
    includeRawContent: true,   // For deep attribute analysis
    ignoreComments: false,     // Attach comments via node.comments[]
    ignoreHeadersAndFooters: false  // Populate ast.auxiliary.headers / .footers
};
