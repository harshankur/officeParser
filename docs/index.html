Powerful Features

Designed for developers who need more than just plain text extraction.

📄

Structural PDF Extraction

A ground-up v8 rewrite. Tagged PDFs yield real headings, tables, lists and footnotes; multi-column pages read in the correct order; broken words, super/subscripts and hyphenation are fixed; and .to('text') is layout-faithful so columns and tables line up like the source page.

🔐

Encrypted Documents

Open password-protected PDF, OOXML (DOCX/XLSX/PPTX) and ODF files through one unified password / onPassword option, across parsing, conversion and templating.

🏗️

Native Generation

Write real DOCX and ODT packages, LaTeX that compiles with pdfLaTeX, XeLaTeX, LuaLaTeX and upLaTeX (CJK included), and PDFs via a native pdf-lib engine that needs no headless browser, running identically in Node and the browser.

🔄

One-Stop API

Powered by OfficeGenerator. Use OfficeConverter.convert for seamless, one-step transformations with Intelligent Auto-Sync.

🧩

RAG Chunking

Native document splitting for AI. Supports fixed-size, structural, and semantic strategies with metadata awareness.

🌳

Structured AST

The foundation for generation. Use .to(format) directly on the AST for high-fidelity conversion.

🌍

Universal Parser

Parses CSV, HTML, Markdown and LaTeX (a .tex file or a whole Overleaf project .zip) as input formats, enabling true any-to-any document pipelines.

📎

High Fidelity

Unmatched support for merged table cells, anchors, bookmarks, and complex document hierarchies. Content kept apart from the text is read where it stands: SmartArt, text boxes, content controls, embedded HTML and RTF chunks, comments with their replies, and RTF headers and footers.

⚡

Extreme Performance

Up to 23x speedup for ODP parsing; highly optimized engines for RTF, PDF, and large Excel workbooks.

🔍

Vision & OCR

Seamlessly read text from images within documents using our integrated, pooled Tesseract.js worker engine.

⚙️

Deep Metadata

Access full document properties, author info, and custom XML/ODF properties across all major formats.

Optimized for AI

Native RAG & Chunking

Don't just split text, understand it. Our structural chunking preserves the semantic context that naive splitters destroy.

📑

Heading Awareness

Chunks automatically inherit the context of their parent headings, ensuring the LLM knows the exact topic of every fragment.

📍

Physical Metadata

Every chunk includes its physical origin: page number, slide name, or sheet index from the original source document.

📊

Table Integrity

Intelligent row-level splitting for large tables. Automatically repeats headers in every chunk to maintain structural clarity.
